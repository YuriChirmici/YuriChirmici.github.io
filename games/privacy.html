Privacy Policy

YukiForge Games

Last updated: 22 November 2026

In short

YukiForge Games is an independent developer of small mobile games. This policy covers this website and the tools the studio uses for its own work, such as uploading its videos to its YouTube channel. Each game has its own privacy policy, which describes the data that game uses.

Our games

Every game has its own privacy policy, linked next to the game on the studio page.

This website

The site is a set of static pages. It has no accounts, no forms, no cookies and no analytics or advertising scripts of ours. It is hosted on GitHub Pages; GitHub may log technical data such as IP addresses to run and protect the service, as described in the GitHub Privacy Statement.

YukiForge uploader (YouTube API Services)

YukiForge uploader is an internal tool. Only the studio uses it, signed in with the studio's own Google account, to upload the studio's own gameplay videos to its YouTube channel and to read that channel's name. It uses YouTube API Services; by using it we are bound by the YouTube Terms of Service, and Google's processing is described in the Google Privacy Policy.

The tool does not access, collect, store or share data of any other person. The sign-in token stays on the studio's own computer and is never sent anywhere except to Google. Access can be revoked at any time on the Google security settings page.

Children

This website and the studio's tools are not directed at children and collect no personal data from anyone.

Changes

If this policy changes, the new version is published on this page with a new date.
